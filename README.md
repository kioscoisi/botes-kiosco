# botes-kiosco

Robot que lee cada hora los botes y fechas de los próximos sorteos de la web oficial de
Loterías y Apuestas del Estado y los guarda en `botes.json`, para la web del Kiosco Isi
(receptor 91300, Zamora). Se ejecuta también todos los días a las 22:00 (hora de España).

**Estado:** la web oficial responde 403 (bloqueo) a los servidores de GitHub, por lo que la
ejecución programada está desactivada. El robot sigue disponible para ejecutarlo a mano.
